## 🔎 Selected projects

### 🌐 [Social Networks, Matching & Disease Diffusion](https://github.com/ceciliaalocicero/online-networks-sti-simulation)

Agent-based simulation exploring assortative matching, hub formation and STI spread, calibrated using approximately **60,000 OKCupid profiles**.

**My contribution:** Led Python implementation in a four-person team, including matching and relationship dynamics, scenario comparisons and network validation. Simulated **1,000 agents over 730 days across five random seeds**.

`Agent-based modelling` · `Network science` · `Python` · `NetworkX`

### 💬 [StockTwits Sentiment & Asset Pricing](https://github.com/ceciliaalocicero/stocktwits-sentiment-asset-pricing)

Analysis of **5.6 million StockTwits posts**, combining sentiment-model evaluation with attention metrics and asset-pricing tests.

**My contribution:** Developed abnormal-attention metrics accounting for user concentration, multi-ticker posts and historical activity; analysed attention and sentiment results within the team project.

`Behavioural signals` · `NLP` · `Metric design` · `Asset pricing`

### 🗣️ [Italian Political Discourse NLP](https://github.com/spulidori/italian-political-discourse-nlp)

Multilingual analysis of how Italian parliamentary and UN speeches frame migration and military policy, combining stance classification, topic modelling and hierarchical summarisation.

**My contribution:** Led data preparation and implemented translation and hierarchical summarisation. The team's classifier achieved approximately **0.81 development macro-F1**, complemented by a separate manual validation exercise.

`Multilingual NLP` · `Transformers` · `Topic modelling` · `Model evaluation`

### 📈 [ML Return Prediction on the S&P 500](https://github.com/ceciliaalocicero/ml-return-prediction-sp500)

Team project comparing linear models, generalised additive models, tree-based methods and a neural network on **2010–2023** data.

**Evaluation:** Purged split, rank information-coefficient tests and a portfolio backtest accounting for transaction costs.

`Machine learning` · `Financial data` · `Temporal validation` · `Backtesting`
