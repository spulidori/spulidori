## Selected projects

- **[Italian Political Discourse NLP](https://github.com/spulidori/italian-political-discourse-nlp)**
  Compares how Italian parliamentary and UN speeches frame migration and military
  policy, using BERT stance classification, LDA topic modeling, and hierarchical
  summarization.

- **[Disease Diffusion on Online Dating Networks](https://github.com/ceciliaalocicero/online-networks-sti-simulation)**
  Agent-based simulation of assortative matching, hub formation, and STI spread
  (SEIS dynamics) built on OKCupid profile data. *[Team project with @ceciliaalocicero]*

- **[ML Return Prediction on the S&P 500](https://github.com/ceciliaalocicero/ml-return-prediction-sp500)**
  OLS, GAM, tree-based models, and a neural net (2010–2023) evaluated with a purged
  split, rank-IC tests, and a cost-aware portfolio backtest.

- **[StockTwits Sentiment & Asset Pricing](https://github.com/ceciliaalocicero/stocktwits-sentiment-asset-pricing)**
  Sentiment models benchmarked on 5.6M StockTwits posts, plus an abnormal-attention
  factor tested with portfolio sorts and Fama-French five-factor regressions.
